# متجر تويس للتسوق (Twis E-Commerce Store) 🏺🥜

متجر إلكتروني احترافي وعصري باللغة العربية، مصمم خصيصاً لمدينة **السمارة بالصحراء المغربية**، لبيع:
1. **الأواني المنزلية ومستلزمات المطبخ** (قدور جرانيت وإينوكس، براريد الشاي الفضية، طواجن مغربية، صواني التقديم والضيافة، أدوات الطبخ وحافظات الطعام).
2. **الفواكه الجافة والمكسرات الفاخرة** (اللوز البلدي المحمص، الكاجو الجامبو، الفستق الحلبي، عين الجمل، تمور المجهول، المشمش والتين المجفف، وخلطات الطاقة والضيافة الملكية).

---

## 🌟 أبرز مميزات المتجر

### 1. هوية وتصميم مغربي عصري ودافئ
- ألوان دافئة وفخمة مستوحاة من التراث المغربي وألوان التوابل والمكسرات (العنبر، الزعفران، الأخضر الزمردي والذهبي الدافئ).
- دعم كامل للغة العربية واتجاه اليمين إلى اليسار (`RTL`) مع خطوط أنيقة (`Tajawal` و `Cairo`).
- تجربة مستخدم سريعة ومتجاوبة 100% مع الهواتف الذكية وأجهزة الكمبيوتر (**Mobile-First Design**).

### 2. نظام المنتجات واختيار الوزن الديناميكي للفواكه الجافة
- بطاقات منتجات أنيقة تحتوي على صور عالية الدقة، شارات الخصومات والأكثر مبيعاً.
- **نظام الأوزان المتعددة للفواكه الجافة**:
  - إمكانية اختيار الوزن: `250g` (ربع كيلو)، `500g` (نصف كيلو)، `1kg` (كيلوغرام كامل).
  - تحديث السعر تلقائياً وفورياً على البطاقة وداخل نافذة التفاصيل السريعة.
- نافذة المعاينة السريعة (Quick View Modal) مع تفاصيل المنتج ومميزاته وزر استفسار واتساب فوري.

### 3. الدفع عند الاستلام (COD) وتأكيد الطلب الفوري
- طريقة الدفع الأساسية هي **الدفع نقداً عند الاستلام (Cash on Delivery)** بدون الحاجة لأي بطاقة بنكية.
- استمارة إتمام الطلب بسيطة وسريعة بدون خطوات معقدة:
  - الاسم الكامل
  - رقم الهاتف المغربي (يبدأ بـ 06 أو 07)
  - المدينة والحي بالسمارة (حي الوحدة، حي السلام، حي العودة، حي المسيرة، حي الركيب، وسط المدينة...)
  - العنوان بالتفصيل وملاحظات التوصيل
- توليد **رقم طلب فريد** (مثل `#SMR-2026-4819`).
- صفحة نجاح الطلب مع زر **إرسال تفاصيل الطلب عبر واتساب** للتأكيد الفوري مع صاحب المتجر.

### 4. نظام سلة المشتريات المتطور
- سلة جانبية منبثقة (Cart Drawer) بالإضافة لصفحة سلة كاملة.
- شريط احتساب التوصيل المجاني بالسمارة تلقائياً (مثال: "أضف 45 د.م للاستفادة من التوصيل المجاني").
- تعديل الكميات وحذف العناصر بسلاسة.

### 5. لوحة تحكم الإدارة الشاملة (Admin Dashboard)
- محمية برمز مرور (PIN الافتراضي: `12345`).
- **إحصائيات فورية**: إجمالي المبيعات بالدرهم (MAD)، عدد الطلبات، الطلبات الجارية، المنتجات المتوفرة.
- **إدارة الطلبات**:
  - عرض تفاصيل كل طلب وطباعة الفاتورة.
  - تغيير حالة الطلب مع حفظ السجل الزمني (`جديد` ⬅️ `تم التأكيد` ⬅️ `قيد التجهيز` ⬅️ `خرج للتوصيل` ⬅️ `تم التسليم` ⬅️ `ملغى`).
  - البحث والفلترة برقم الطلب، اسم الزبون، أو رقم الهاتف.
  - زر مراسلة الزبون بالواتساب بنقرة واحدة.
- **إدارة المنتجات**:
  - إضافة منتجات جديدة (أواني منزلية أو فواكه جافة متعددة الأوزان).
  - تعديل الأسعار، المخزون، ونسب التخفيض.
  - إمكانية رفع صور من جهاز الكمبيوتر أو وضع رابط الصورة.
  - تفعيل وسم "الأكثر مبيعاً" و"المميز".
- **إعدادات التوصيل والمتجر**:
  - تعديل تكلفة التوصيل داخل السمارة وحد التوصيل المجاني.
  - تعديل رقم هاتف المتجر ورقم الواتساب.
- **النسخ الاحتياطي واسترجاع البيانات**:
  - تصدير كافة بيانات المتجر إلى ملف `JSON`.
  - استيراد نسخة احتياطية سابقة بنقرة زر.

### 6. ميزات الهاتف الذكي (Mobile Experience)
- شريط تنقل سفلي سريع (Bottom Navigation Bar).
- زر واتساب عائم عالي الاستجابة.
- زر اتصال هاتفي مباشر بنقرة واحدة.
- صفحة تتبع الطلبات للزبائن برقم الهاتف أو رقم الطلب.

### 7. تهيئة محركات البحث (SEO)
- عناوين ووصف دقيق وكلمات مفتاحية مخصصة للسمارة: *"أواني منزلية السمارة"*, *"فواكه جافة السمارة"*, *"مكسرات السمارة"*.
- بيانات منظمة Schema.org (JSON-LD) لمتجر محلي بالسمارة.

## 🚀 طريقة تشغيل المتجر

### الطريقة 1: التشغيل بنقرة واحدة (موصى بها على ويندوز)
فقط انقر مرتين على الملف:
```
start-server.bat
```
سيقوم تلقائياً بتشغيل الخادم المحلي وفتح المتجر على الرابط:
`http://localhost:8080/`

### الطريقة 2: فتح الملف مباشرة في المتصفح
يمكنك فتح ملف `index.html` في أي متصفح (Chrome, Edge, Firefox) مباشرة دون الحاجة لأي خادم، حيث يعمل المتجر بنظام تخزين محلي كامل (`LocalStorage`).

### الطريقة 3: عبر PowerShell
افتح مجلد المشروع في PowerShell وشغّل:
```powershell
.\server.ps1
```
